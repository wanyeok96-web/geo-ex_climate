## 1. 파트 목표
- 기후 그래프에서 기온·강수의 특징을 읽음
- 쾨펜의 1·2·3차 기준을 이해함
- 기후 그래프로 기후 기호를 판별함

## 2. 파트의 역할
- PART 5(세계의 기후대)에서 Af·Cfb 같은 **기후 기호를 바로 읽을 수 있게** 준비
- PART 1의 기후대 색·이름 → PART 4에서 **기준(수치)** 으로 정리
- 판별 기준(아래 4절)은 PART 5·6의 도시 판별에서 그대로 사용 (`js/ui/koppen.js`)

## 4. 판별 기준 (교과서 기준 — 앱 전체 공통, `js/ui/koppen.js`)

| 차수 | 순서 | 기준 | 결과 |
|---|---|---|---|
| 1차 | ① | 최난월 < 10℃ | **E** 한대 |
| | ② | 연강수량 < 500mm | **B** 건조 |
| | ③ | 최한월 ≥ 18℃ | **A** 열대 |
| | ④ | 최한월 > −3℃ / ≤ −3℃ | **C** 온대 / **D** 냉대 |
| 2차 | A | 최소우월 ≥ 60mm → f / 최소우월 ≥ 100 − 연강수량÷25 → m / 그 밖 → w | Af · Am · Aw |
| | B | 연강수량 < 250mm → W / 250~500mm → S | BW · BS |
| | C·D | 여름 건조(여름 최소우월 < 40mm, 겨울 최다우월 ≥ 그 3배) → s / 겨울 건조(여름 최다우월 ≥ 겨울 최소우월 × 10) → w / 그 밖 → f | Cs · Cw · Cf / Df · Dw |
| | E | 최난월 0~10℃ → T / < 0℃ → F | ET · EF |
| 3차 | Cf | 최난월 ≥ 22℃ → a / < 22℃ → b | Cfa · Cfb |

- 여름 반년: 북반구 4~9월, 남반구 10~3월
- 교과서 13유형: Af · Am · Aw · BW · BS · Cfa · Cfb · Cs · Cw · Df · Dw · ET · EF (+ 고산 H)
- 앱 도시 자료(97개 도시, 고산 제외) 교과서 유형과 **92곳 일치**. 다른 5곳(경계값 근처): 자카르타·라고스·아바나 Aw→Am, 밴쿠버 Cfb→Cs, 코르도바 Cw→Cfa → 선생님 확인 필요(아래 7절)
- 세계 기후 지도(1-2)의 건조 기후 경계: 기온·강수 계절을 반영한 정밀 기준(건조 한계(mm) = 20 × 연평균 기온 + 280 · 140 · 0 — 여름·고르게·겨울에 강수가 많을 때) 적용 → 4-2 「참고」 블록에서 안내
