## ① 파트 뼈대

### 1. 파트 목표
- 기후 요소(기온·강수·바람)의 뜻과 나타내는 방법을 이해함
- 기후 요인이 기후 요소를 지역마다 다르게 만드는 과정을 사례로 설명함
- 1-3 탐구 질문 3·4·5의 답을 찾음

### 2. 파트의 역할
- PART 1(기후의 이해)과 PART 3(대기대순환)을 잇는 **개념 다리**
  - 기압·바람·상승 기류와 강수 → PART 3 대기대순환의 바탕 개념
  - 연교차·연강수량·강수 계절 → PART 4 기후 그래프 읽기의 바탕 개념
- 탐구 질문 해결
  - 질문 3 (런던이 퀘벡보다 따뜻한 까닭) → 2-2 해류·수륙 분포
  - 질문 4 (우리나라 여름 강수 집중) → 2-2 계절풍·기단과 전선
  - 질문 5 (적도 부근 서늘한 도시) → 2-2 지형(해발 고도)
- 대기대순환(기압대·바람대)은 요인 소개만 → 자세한 원리는 PART 3

### 4. 노드형 블록 — 이 파트에서 처음 만드는 화면 방식

#### 4-1. 모습
한 블록(화면 한 장) 안에서 **개요 화면 ↔ 노드 화면**을 오가는 방식.

```
[개요 화면]                                  [노드 화면 — 「기온」을 누른 뒤]
┌─────────────────────────────┐            ┌─────────────────────────────┐
│ 기후 요소란?                    │            │ ⌂개요 │[기온]│ 강수 │ 바람 │  ← 노드 막대
│ · 기후를 이루는 대기 현상         │            │ ① 뜻·측정  ② 평균 기온  ③ 연교차 │  ← 소주제 칩
│ · 3대 요소: 기온·강수·바람        │   누르면    │ ┌──────────┐┌──────────────┐ │
│ · 그 밖: 습도·일조·구름양          │  ───────▶  │ │ 개조식 설명  ││  큰 시각 자료    │ │
│                                 │            │ │ 3줄 이내    ││  (그림·그래프·   │ │
│  ┌─────┐ ┌─────┐ ┌─────┐       │            │ │ 용어 칩     ││   조작 버튼)     │ │
│  │🌡️기온│ │🌧️강수│ │🌬️바람│       │            │ └──────────┘└──────────────┘ │
│  └─────┘ └─────┘ └─────┘       │            └─────────────────────────────┘
└─────────────────────────────┘
```

- **개요 화면**: 챕터의 기본 개념(개조식 3줄 이내, 큰 글자) + 노드 카드(아이콘·이름·한 줄 뜻)
- **노드 화면**: 노드를 누르면 같은 블록 안에서 전환
  - 위쪽 **노드 막대**: 「⌂ 개요」 + 노드 이름 전부 → 개요로 돌아가지 않고 다른 노드로 바로 이동
  - **소주제 칩**: 노드 하나에 소주제 2~4개(①②③) → 누르면 설명·시각 자료가 바뀜
  - 본문: 왼쪽 **개조식 설명**(3줄 이내 + 핵심 용어 칩), 오른쪽 **큰 시각 자료**(블록 면적 절반 이상)
  - 시각 자료 안 조작(슬라이더·토글·도시 바꾸기)은 교사가 설명하며 누르는 크기
- 소주제 끝에 관련 챕터 링크 칩(예: 「PART 3 대기대순환 →」, 「1-3 탐구 질문 3의 답」)
- 휴대전화: 설명 위 · 시각 자료 아래로 쌓고 블록 안에서 스크롤

#### 4-2. 규칙
- 노드·소주제 전환은 화면 전환 없이 즉시(동작 줄이기 설정이면 애니메이션 없음)
- 어느 노드를 봤는지는 기록하지 않음. 챕터를 다시 열면 개요 화면부터
- 주소는 `#2-1`·`#2-2`만(기획서 3-5 — 페이지 안 위치는 주소에 넣지 않음)
- 다른 파트에서도 쓸 수 있게 공용 부품으로 제작(`ui/nodes.js`) — 예: PART 5 기후대 6칸
