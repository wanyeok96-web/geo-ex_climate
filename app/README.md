# 지오엑스-세계의 기후

고등학교 「세계지리」(중학교 공용) 기후 파트를 **교사가 교실 스크린에 띄워 처음부터 끝까지 수업할 수 있는 디지털 교과서**입니다.
날씨와 기후에서 시작해 기후 요소·요인, 대기 대순환, 기후 구분과 기후 그래프, 세계의 기후대까지 한 흐름으로 이어집니다.

- 설치·인터넷 연결 없이 **`index.html`을 더블클릭하면 바로 실행**됩니다.
- 이 화면 그대로 교실 TV·전자칠판·프로젝터에 띄워 씁니다. 휴대전화에서는 하단 시트로 목차를 엽니다.
- 현재 상태: **PART 1 · 2 · 4 · 5 · 6 제작 완료, 선생님 확인 대기** — PART 3 대기 대순환은 3D 프로그램 연결.

## 실행 방법

| 방법 | 하는 법 |
|---|---|
| 더블클릭 | `app` 폴더의 `index.html`을 Chrome·Edge로 엽니다. |
| 특정 챕터 바로 열기 | 주소 끝에 `#파트-챕터`를 붙입니다. 예: `index.html#2-2` (기후 요인), `index.html#3-5` (대기 대순환 강수) |
| 웹 배포 | `app` 폴더 전체를 그대로 올립니다(GitHub Pages 등). `tools/` 폴더는 빼도 됩니다. |

## 목차

| 파트 | 챕터 |
|---|---|
| PART 1 기후의 이해 | 1-1 날씨와 기후 · 1-2 세계의 기후 지도 · 1-3 탐구 질문 |
| PART 2 기후 요소와 기후 요인 | 2-1 기후 요소 · 2-2 기후 요인 |
| PART 3 대기 대순환 (3D) | 3-1 대기 대순환이란? ~ 3-8 계절에 따른 기압대의 이동 |
| PART 4 기후 구분과 기후 그래프 | 4-1 기후 그래프 읽는 법 · 4-2 쾨펜의 구분 기준 · 4-3 판별 연습 |
| PART 5 세계의 기후대 | 5-1 열대 ~ 5-6 고산 |
| PART 6 정리와 평가 | 6-1 기후 그래프 탐구 · 6-2 도시 판별하기 · 6-3 교실 퀴즈 |

## 사용 방법

- 왼쪽 목차에서 파트 → 챕터를 고릅니다. 한 챕터는 화면 크기 블록을 위에서 아래로 넘기는 한 페이지입니다.
- PART 3 대기 대순환은 3D 화면 아래의 ◀ ▶ 버튼으로 장면을 넘깁니다.
- 목차 위쪽 « 버튼으로 목차를 접어 화면을 넓게 쓸 수 있습니다.

## 폴더 구조

```
app/
├─ index.html          앱 진입점 (사이드바 + 챕터 페이지)
├─ style.css           전체 디자인 (사이드바는 geo-ex와 같은 모습)
├─ js/
│  ├─ data/            목차(parts.js: 파트·챕터·기후대 색)
│  ├─ core/            공용 도구 · 주소 · 페이지 이동
│  ├─ ui/              사이드바 · 홈·챕터 페이지 · 사용 안내
│  ├─ chapters/        챕터별 기능 (atmos.js = PART 3 3D 연결)
│  └─ main.js          시작
├─ atmos3d/            PART 3 「대기대순환 3D」 (원본 + embed.js 한 파일 추가)
├─ assets/
│  ├─ geopus/          지오퍼스 그림 (지금은 로고만 사용, 나머지는 보관)
│  └─ fonts/           AocSans 글꼴 (SIL OFL)
└─ tools/              개발용 점검 도구 (배포 제외)
```

개발·유지보수 방법은 [`HANDOFF.md`](HANDOFF.md)를 보세요.
